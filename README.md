# Portafolio React Mejorado

## Frontend
1. Instalar dependencias:
   npm install
2. Ejecutar:
   npm run dev

## Backend de contacto
1. Entrar a la carpeta backend
2. Instalar dependencias:
   npm install
3. Ejecutar:
   npm start

El formulario usa el backend en http://localhost:4000/api/contact.
La alerta de visita usa el worker de Telegram configurado en el frontend.
